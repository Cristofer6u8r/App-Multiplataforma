# PlanificaX Lite

Gestor de tareas académicas multiplataforma con Python + Tkinter.

## Requisitos
- Python 3.10+
- Visual Studio Code
- Extensión Python de Microsoft

No requiere paquetes externos.

## Ejecutar
En la terminal de VS Code:

```bash
python app.py
```

En Windows también puede funcionar:
```bash
py app.py
```

La información se guarda en `data/tasks.json`.

## Funciones
- Agregar tareas y prioridad
- Buscar
- Marcar como completada
- Eliminar con confirmación
- Persistencia local
- Atajos Ctrl+N, Enter y Delete
